# Implementation Plan: Split View Data Preview

**Branch**: `002-split-view-preview` | **Date**: 2026-02-11 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/002-split-view-preview/spec.md`

## Summary

Refactor the SQL Database Visualizer's webview layout so that clicking
a table in the schema tree opens a data preview in a right-hand pane
instead of replacing the entire view. This is a pure frontend (webview)
change — no extension host or SQLite service modifications required.
Adds a draggable split pane divider and replaces the "Preview" button
with direct click-to-preview on table names.
